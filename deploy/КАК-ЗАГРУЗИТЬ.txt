!!! ВАЖНО: ОБЫЧНЫЙ ВИРТУАЛЬНЫЙ ХОСТИНГ (public_html) !!!

Timeweb пишет в документации:
Node.js на виртуальном хостинге — только консольная утилита.
Запуск сайта (node server.js) на public_html НЕ РАБОТАЕТ.

Симптом: файлы есть, но в браузере «403 Forbidden».

Нужен один из вариантов:
  • VDS / VPS у Timeweb (есть SSH, node server.js)
  • Timeweb Cloud → App Platform (Next.js + SSR)
  • Бесплатно: Vercel.com (подключить GitHub)

───────────────────────────────────────────────────────

ЕСЛИ У ВАС VDS / VPS (или Cloud App)
───────────────────────────────────────────────────────

1. npm run dist  →  загрузить foodexpress.zip
2. phpMyAdmin  →  timeweb.sql
3. .env рядом с server.js
4. node server.js

───────────────────────────────────────────────────────

ЕСЛИ ТОЛЬКО public_html (ваш случай сейчас)
───────────────────────────────────────────────────────

Сайт Next.js там не заработает. Варианты:

A) Заказать VDS в Timeweb (от ~200–300 ₽/мес)
   — залить zip, node server.js, MySQL как настроили

B) Timeweb Cloud (timeweb.cloud) → Apps → Next.js

C) Vercel — бесплатно для учебного проекта:
   — залить проект на GitHub
   — vercel.com → Import → добавить DATABASE_URL (MySQL с Timeweb)

Поддержка Timeweb: «Нужен ли Node.js как веб-сервер на моём тарифе?»
